# Clavis 1.3.0

A focused writer update: safer documents, a fuller Typst reading experience, and more responsive previews, without a plugin marketplace, terminal or large AI sidebar.

## Documents first

- Saving detects external changes instead of silently overwriting them. Clean buffers reload external edits; conflicting or deleted files pause autosave and offer comparison, merge and scratch recovery copies.
- Session recovery no longer truncates at 50 tabs. All valid recovered drafts and file-backed buffers are retained, including clean scratch documents.
- Save As follows the copied main document's new path and triggers LaTeX compilation even when the text is unchanged. Other chapters retain their existing main-document bindings.
- An offline local version timeline can checkpoint, compare and restore saved documents independently of Git. Restoring updates the editor buffer and keeps save-conflict protection active.
- Start a Typst paper, LaTeX paper or Markdown research note in a new folder from the built-in templates.

## Writing and appearance

- Refreshed Paper/Ink themes, new Mist/Dusk choices and visual theme selection unify editor, chrome and controls.
- Completion suggestions use a compact, quieter popup. A leaking dialog style no longer forces completion labels to uppercase; case-sensitive command names, references and paths are preserved.
- Optional inline formulas keep the cursor/selection line editable as source. Formula and reference hovers, heading/environment folding and syntax-aware prose assistance support writing without extra permanent panels.
- Diagnostics retain the original compiler message and add relevant source, environment, package or rebuild actions. Environment checks report available tools without installing software.

## Typesetting and reading

- LaTeX and Typst share project-main selection, with session-persisted document overrides. Preview/export snapshots include the project's unsaved file-backed buffers.
- Typst preview supports pages, text selection, whole-document find, page navigation, internal references and nearest-source navigation. Recompilation keeps the current search selection and reading position.
- Typst packages are resolved from local caches; missing preview packages require explicit download confirmation. Compilation never downloads packages automatically.
- LaTeX offers quick preview, clean rebuild, optional trusted latexmk full builds and process-tree cancellation. Auxiliary-only caching still uses fresh source snapshots.
- Opening a LaTeX document now starts its initial automatic compile. A failed optional PDF text layer no longer hides a successfully rendered page; preview failures are visible rather than silent blanks.
- PDF find indexes text on every page, not just currently rendered pages. Remote results, cross-text-run matches and repaint-stable highlighting work without rendering the whole document.
- Preview zoom immediately scales existing surfaces and defers nearby sharp repaints until input settles. Returning to a previous scale restores cancelled text extraction/rendering, so selection and highlights do not remain broken.

## Long-document work

- Project-scoped preview revisions and dependency monitoring avoid unrelated tab changes and refresh changed includes/assets.
- Prose analysis updates affected lines instead of rescanning the entire document for ordinary edits.
- Typst reuses source state, bounds its SVG cache and omits unchanged SVG strings already held by the frontend. Only nearby page surfaces remain mounted; full text remains searchable.
- These changes reduce redundant work. They are not a guarantee of a particular frame rate or instantaneous compilation for arbitrary documents.

## Validation and boundaries

- Local checks: 634 frontend tests, 141 Rust tests and 8 release-guard tests pass, along with TypeScript, production frontend build and Rust all-target checks. Three optional Rust tool/benchmark tests are skipped by default.
- The local macOS candidate builds and passes ad-hoc signature verification. Real TeX/PDF.js checks locate a match on page 11 of a 12-page PDF without rasterizing any page. Prior native-tool checks also exercised starter templates, latexmk/index generation and synthetic long Typst documents.
- Native GUI feel, complex text-layer alignment and an actual old-app-to-new-app upgrade remain manual acceptance items. Automated tests do not claim those have passed.
- Previously truncated and overwritten session contents cannot be recovered by this update. Local history is path-keyed, limited to 50 versions per document and 256 MiB globally, and is not a backup service.
- Inline formulas are single-line previews without arbitrary document macros/imports. Literal search does not span page boundaries; PDF search does not perform OCR. Save As does not copy an entire project or rewrite its includes/configuration.
- macOS is ad-hoc signed, not Apple-notarized; Windows installers do not have Authenticode signing. First-install security prompts may occur. Signed updater packages use the existing update key, unchanged.

## Installation

Use the macOS Apple Silicon DMG, Windows x64 setup, or Linux x64 AppImage/DEB attached to this release. Existing installations can check for updates after publication. Homebrew users can upgrade the `ziwangprincex/clavis/clavis` cask after its distribution workflow completes.
