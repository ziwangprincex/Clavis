# Clavis 1.2.0

A quieter writing workspace, with more reliable document state, saves and previews.

## Writing experience

- A simplified document toolbar, calmer status bar, and Paper/Ink themes keep the document in focus.
- Write, Split, Read and temporary Focus modes adapt the workspace without losing pane preferences.
- Workspace views group documents, research and review tools. Hiding the sidebar no longer leaves a blank strip and preserves its current view, expanded sections and directory state.
- Responsive sidebar and editor/preview constraints keep narrow windows usable, then restore the preferred widths when the window grows.
- Each open document keeps its own undo history, selection and editor scroll state.

## Reliability and performance

- Manual save, Save As and autosave share a queue, preventing stale writes and incorrectly cleared dirty states.
- LaTeX builds use fresh source snapshots containing open buffers and project resources. Failed builds no longer expose a previous PDF as a successful result.
- Project-aware SyncTeX and PDF ownership prevent navigation and preview results from leaking across unrelated documents.
- PDF replacements are staged before swapping into view to preserve the reading position and reduce blank flashes.
- Hidden previews stop scheduling automatic work. Reopening renders the latest content; explicit compile and export remain available.
- Typst SVG and PDF compilation runs on background workers. Live preview coalesces pending requests and ignores stale results.
- Typst preview reloads included files and images when reopened instead of relying on a source-only cache.

## Build and release

- Unified root build commands and pinned command-library preparation replace local build overrides.
- Tag releases must pass frontend, Rust and release-guard checks before creating the release draft.
- Homebrew's generated macOS requirement uses the supported `>= 11.0` form.
- Version preparation works with the macOS system Python 3.9.

## Validation and limitations

- Local verification: 491 frontend tests, 119 Rust tests and 8 release-guard tests; frontend typecheck, production build and Rust all-target checks passed.
- Native interaction acceptance and an actual update from an older installed app are not recorded as completed. Automated tests are not a measurement of GUI smoothness.
- Cancelling preview work invalidates pending requests/results; it does not forcibly terminate a running native compilation.
- macOS builds are ad-hoc signed, not Apple-notarized; Windows installers do not have Authenticode signing. First-install operating-system security prompts may occur. Updater package signatures are separate and remain enabled.

## Installation

Download the installer for your platform from this release: macOS Apple Silicon DMG, Windows x64 setup, or Linux x64 AppImage/DEB.

Existing installations can use Settings → Updates → Check for Updates after the release is published. Homebrew users can upgrade the `ziwangprincex/clavis/clavis` cask after its update workflow completes.
