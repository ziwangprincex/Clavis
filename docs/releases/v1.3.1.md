# Clavis 1.3.1

A quieter writing workspace with safer saving and more reliable previews. This release includes the full writer update intended for 1.3.0, whose release build failed before installers were published. Existing 1.2.0 installations can update directly to 1.3.1 after publication.

## Writing workspace

- Refined Paper/Ink palettes, Mist/Dusk themes, calmer toolbars and tabs, and more comfortable editor and preview spacing.
- Compact completion suggestions preserve the original case of LaTeX commands, references and paths. A leaking dialog style no longer forces labels to uppercase.
- Optional inline formulas, formula/reference hovers, heading and environment folding, and syntax-aware prose assistance support writing without extra permanent panels.
- Diagnostics keep the compiler's original message and offer relevant source, environment, package and rebuild actions.

## Safer documents

- Saving detects external changes rather than silently overwriting them. Clean buffers reload external edits; conflicts and deleted files pause autosave and offer comparison, merge and scratch recovery.
- Session restoration retains all valid drafts and file-backed buffers instead of truncating at 50 tabs.
- Save As follows a copied main document's new path and refreshes LaTeX compilation without redirecting other chapters.
- Built-in starter templates and an offline local version timeline work without Git. Restoring a version changes the buffer and keeps save-conflict protection active.

## Typesetting and previews

- LaTeX and Typst share project-main selection and session-persisted overrides; preview/export snapshots include unsaved file-backed project buffers.
- Typst adds paged reading, text selection, whole-document find, navigation and source links. Recompilation preserves the current search selection and reading position.
- Typst resolves packages locally and asks before downloading missing preview packages; compilation never downloads them automatically.
- LaTeX offers quick preview, clean rebuild and optional trusted latexmk builds. Opening a LaTeX file starts its initial automatic compile; a failed optional text layer no longer hides a successfully rendered PDF page.
- PDF search indexes every page independently of virtualized page rendering. Distant results, cross-text-run matches and stable highlighting no longer depend on visible canvases.
- Preview zoom scales existing surfaces immediately and defers sharp nearby repaints until input settles. Returning to an earlier scale restores cancelled text extraction and rendering.
- Project/dependency-scoped invalidation, incremental prose analysis and cached Typst surfaces reduce redundant long-document work without promising a particular frame rate.

## Reliability

- Unix process-group cancellation now separates command options from negative group IDs, preventing older Linux kill implementations from targeting the caller's group.
- CI compiles tests separately and runs them serially with a bounded execution time. All existing tests and publication gates remain enabled; the failed 1.3.0 tag is not moved or reused.

## Boundaries

- Native GUI feel, complex text-layer alignment and an actual installed-app upgrade still require manual acceptance; passing automated checks does not establish these.
- macOS builds are ad-hoc signed, not Apple-notarized; Windows installers do not have Authenticode signing. First-install security prompts may occur. Updater packages use the existing signing key.
- Local history is path-keyed, limited to 50 versions per document and 256 MiB globally, and is not a backup service. This update cannot recover session contents already overwritten by older versions.
- Inline formulas are single-line previews without arbitrary document macros/imports. Search does not span page boundaries or perform OCR. Save As does not copy an entire project.

## Installation

Download the macOS Apple Silicon DMG, Windows x64 setup, or Linux x64 AppImage/DEB attached to this release. Existing installations can use Check for Updates after publication. Homebrew users can upgrade the `ziwangprincex/clavis/clavis` cask once its distribution workflow completes.
