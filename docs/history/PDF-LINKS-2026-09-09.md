# PDF citation links: detached page preparation

2026-09-09, local follow-up. No commit, push, tag or remote release authorized.

## Root cause

The initial Link annotation overlay checked `!layer.isConnected` as soon as
`getAnnotations()` completed. `PdfPages.prepare()` deliberately paints the
first reading region off-DOM, and later pages/zoom replacements also render a
new surface before installing it. Annotations that resolved during this valid
detached phase were discarded permanently; the successful canvas did not retry
link generation. The initial four link tests only checked destination parsing,
not link hit areas or actual viewer scroll wiring.

## Fix

- Populate detached link layers unless the document is disposed. Do not use DOM
  connection state to reject prepared content.
- Check connection when an asynchronous click resolves, so an evicted surface
  cannot trigger a late jump. Link clicks prevent default navigation and stop
  propagation to SyncTeX.
- Give the link overlay explicit stacking above the text layer, while leaving
  non-link regions available for selection and reverse SyncTeX.
