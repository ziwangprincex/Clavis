# Writer reliability fixes · 2026-09-08

The owner authorized all six defects identified in the local audit. This is a local candidate, not a new release. Existing unrelated worktree changes are preserved. No dependencies, release version, remote refs, signing credentials or production updater configuration are changed by this pass.

## Fixed behavior

- **Session recovery:** removed the 50-tab truncation rather than adding priority/fallback policies. Every valid, deduplicated snapshot entry is restored in order, with the active tab preserved. This includes clean scratch documents, which have no independent file, as well as dirty file-backed buffers. Existing schema validation and path deduplication are retained. This cannot recover content an earlier app already discarded and overwrote in its snapshot; session recovery is not a backup guarantee.
- **Save As main identity:** after a successful path-changing save, a document that was its own resolved main follows its new path. This applies to explicit, workspace-configured, collected and standalone roots, and LaTeX/Typst. Existing open chapters are not redirected to the copy; explicit chapter-to-parent bindings remain intact. Cancelled/conflicting saves leave identity untouched. Save As is not a project migration: it does not copy dependencies or rewrite source includes, magic comments or workspace configuration.
- **LaTeX auto compile:** the existing single debounce now observes file path, explicit root and engine override as well as content/identity/language. A first save or path-only Save As schedules compilation without requiring an extra edit. Hidden/disabled previews remain paused; title-only updates do not compile.
- **PDF full-document find:** a document-scoped text index reads every page on demand when a query is entered. It does not allocate offscreen canvases or text layers. Text extraction is cached per document, periodically yields, stops fetching after cancellation, and stale searches cannot publish results. Queries are literal, support case sensitivity and span adjacent text items/line breaks within a page. Extraction failures are shown instead of a misleading partial/zero count. Image-only PDFs still need OCR; search does not span page boundaries or expand typographic ligatures.
- **PDF search presentation:** global match identity/count is independent of mounted surfaces. Navigation uses existing page wrappers and a scale-independent match coordinate, so remote results work before their text is mounted. PDF.js's public text-item/div mapping projects highlights onto only mounted text layers. Repaint/eviction does not reset counts, navigate or select the first match. Recompiled output preserves an existing selected occurrence where its page/offset still matches, otherwise its bounded ordinal.
- **Typst search refresh:** only a changed query navigates automatically. Recompiled pages refresh highlights/counts, keep the selected page/offset where possible, and clamp a removed occurrence without scrolling the reader back to the beginning. Explicit previous/next still navigates.
- **PDF cancelled text recovery:** canvas readiness and selectable-text readiness are tracked separately. Zooming away and back while either extraction or text rendering is pending restarts only the cancelled text layer at the existing sharp canvas scale. Completed text is not rebuilt unnecessarily. Revision guards discard late completion; evicted layers release their DOM references. Text failures never hide a successful canvas.
